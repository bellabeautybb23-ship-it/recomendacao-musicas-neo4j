Algoritmo de Recomendação de Músicas com Base em GrafosProjeto de Desafio da DIO - Banco de Dados em Grafos com Neo4j. Contexto do ProblemaAplicativos como Spotify e Deezer precisam recomendar músicas que o usuário ainda não ouviu, mas que tem grande chance de gostar.Em um banco relacional isso é complexo, cheio de JOINs. Em um banco de grafos, isso é natural: a recomendação é apenas um caminho no grafo.A lógica usada é Filtragem Colaborativa:"Se você e outra pessoa ouviram as mesmas músicas, e essa pessoa ouviu uma música nova, provavelmente você também vai gostar dela." Por que Grafos?Escolhi o Neo4j porque:Relacionamento é dado: O OUVIU já é a conexão, não precisa de tabela intermediária.Performance: Encontrar "amigos de amigos" em grafo é muito mais rápido que em SQL.Visual: Dá pra ver o grafo e entender a recomendação na hora.Modelo do GrafoNós:Usuario {id, nome, cidade}Musica {id, titulo, ano}Artista {nome}Genero {nome}Relacionamentos:(Usuario)-[:OUVIU {vezes}]->(Musica)(Musica)-[:DE_ARTISTA]->(Artista)(Musica)-[:DO_GENERO]->(Genero)(Usuario)-[:CURTIU]->(Musica)Modelo do Grafo
